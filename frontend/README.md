# CodePilot Frontend

React/Vite frontend for the AI Software Engineering Copilot.

## Setup

```bash
npm install
npm run dev
```

Optional `.env`:
```env
VITE_API_URL=http://localhost:3000/api
```

Implemented foundation:
- Login and registration
- Protected routes
- Developer dashboard
- GitHub repository connection
- Repository listing and deletion
- Repository details
- Repository indexing
- Responsive developer-focused UI

The AI cards are the next UI layer to connect to the existing backend AI endpoints.
